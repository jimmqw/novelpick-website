## 13:05 主题一：SEO最新动态 - LLM可见性

### 核心要点
**从流量KPI转向可见度KPI**
- AI搜索（ChatGPT/Perplexity/Gemini/Claude）正在抢占传统搜索份额
- 品牌需要在AI生成的答案中被引用，这比传统排名更有价值
- Semrush研究：2027年LLM流量可能完全超越Google搜索

**4个AI可见性增长信号**
1. 有机流量下降 + 品牌搜索稳定 → 人们先在其他地方发现你
2. 销售电话提到"通过AI找到你"
3. 直接流量稳定尽管Google点击减少
4. 竞争对手SEO弱但份额在增长

**AI引用内容的特征**
- 原创数据/研究报告（AI无法从其他地方获取的）
- 结构化数据（Schema标记）
- 多平台第三方提及（Reddit、行业媒体、评测平台）
- 清晰定义和FAQ内容

### 实践建议
- 追踪品牌在AI平台中的提及（Semrush AI Visibility Toolkit）
- 创造原创研究数据，吸引AI和记者引用
- 布局多平台存在：Reddit、行业论坛、PR覆盖

**来源：** Backlinko LLM Visibility, Semrush AI Visibility

## 13:20 主题二：AI Agent开发与服务 - Agentic AI

### 核心要点
**AI Agent ≠ AIO（Agentic AI Optimization）**
- 演进路径：SEO → AEO → GEO → AAIO
- AI Agent理解网站三种方式：
  1. 视觉/截图（Anthropology Computer Use, Google Project Mariner）
  2. **Accessibility Tree（结构化）** - OpenAI Atlas明确使用ARIA标记
  3. 混合（OpenAI CUA, Perplexity Comet）

**Accessibility Tree是Agent主要界面**
- 关键发现：标准条件下Agent成功率68%，无障碍信息后下降至12%
- 网站优化建议：语义HTML、ARIA roles/labels、稳定布局、label关联input
- 双重收益：为Agent优化 = 为无障碍优化

**Google官方Agent优化指南**
- WebMCP协议让网站注册agent-ready工具
- "Build agent-friendly websites"成为新标准
- Agent化设计 ≠ 人类友好设计（但通常重叠）

**来源：** Search Engine Journal - How AI Agents See Your Website

## 13:50 主题四：内容营销 - 垂直细分策略

### 核心转变：从"为所有人写"到"为我写"
- LLM查询越来越长尾个性化
- 只有深度细分的内容才能被LLM拼出定制答案
- Backlinko 2026内容路线图：按行业、公司规模等维度生产针对性内容

### TOFU内容新价值
- AI Overviews直接回答顶部问题导致点击减少
- 新KPI：赚取外链 + LLM引用次数，而非页面浏览量
- 成功案例：Gusto数据报告被Business Insider/Fast Company引用

### 社区信号权重上升
- Reddit/Quora/论坛 discussions影响AI发现
- AI不信任单一网站，而信任"信号生态系统"
- 策略：在第三方平台保持活跃存在

### Ghost Citation问题
- 62%的LLM答案"凭空"引用不存在的产品
- 只有13.2%的情形同时提到真实产品
- 品牌需要主动在AI平台建立存在
