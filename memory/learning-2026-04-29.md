# 每日学习笔记 - 2026-04-29

## [19:15] SEO 2026趋势：从意图驱动到人设驱动

### 核心要点
1. **AI Overviews（零点击搜索）已成主战场**：Google的AI Overview直接回答大量查询，传统TOFU内容流量大幅下降。需要优化出现在AI Overview中的能力。
2. **外链依然重要但格局变了**：Google称链接重要性下降，但数据表明链接仍是核心排名信号。更重要的是LLM引用——ChatGPT等会从第三方网站引用，品牌需要在多处被提及。
3. **TOFU内容转型**：顶部漏斗内容不再以流量为KPI，而是以"赚取外链+LLM引用"为目标。数据驱动原创内容（调研、数据报告、统计）最有价值。
4. **细分内容崛起**：AI搜索让查询越来越个性化（"适合弗吉尼亚州独立平面设计师、收EUR和USD的发票工具"），只有深度细分的内容才能被LLM拼凑出定制答案。
5. **策略转型：意图驱动→人设驱动**：同一查询，AI给不同用户不同答案。内容策略要考虑具体用户画像，而非仅搜索意图标签。
6. **视频SEO持续增长**：YouTube SEO和TikTok SEO搜索量稳定增长，值得投入。
7. **语音搜索仍是泡沫**：多年未实现大规模采用，不值得专门优化。
8. **Core Web Vitals**：对大站更有价值，小站不必执念满分。

## [19:35] 内容营销在AI时代的新规则

### 核心要点
1. **原创数据是护城河**：Gusto的数据报告被Business Insider和Fast Company引用→品牌权威+LLM素材。
2. **SoFi案例**：一篇关于"各州历史油价"的文章，Google排名不高，但在LLM中被广泛引用——新KPI是LLM引用率而非搜索排名。
3. **"为我而写" > "为所有人写"**：宽泛内容在AI时代被淹没，精准为某类人写的内容胜出。
4. **质量>数量原则强化**：SEJ明确指出"SEO没死，烂内容死了"。AI滥用导致低质内容泛滥，真正有人类经验和洞察的内容价值反而上升。
